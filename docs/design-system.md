# Дизайн-система фронтенду

Усі кольори, розміри тексту, радіуси й відступи беруться зі змінних у `src/styles/tokens.css`.
Нові стилі пишіть через змінні, а не через hex-значення.

## Токени

| Група | Змінні | Призначення |
| --- | --- | --- |
| Поверхні | `--bg-0` … `--bg-3`, `--bg-sel` | сторінка, панелі, поля, hover, вибраний стан |
| Межі | `--border-1` … `--border-3` | ледь помітна, стандартна, підкреслена |
| Текст | `--text-1`, `--text-2`, `--text-3` | основний, другорядний, підписи (контраст ≥ 5:1 на всіх поверхнях) |
| Акцент і стани | `--accent`, `--ok`, `--warn`, `--bad`, `--focus-ring` | |
| Шрифт | `--fs-xs` 11px, `--fs-sm` 12px, `--fs-md` 13px | мінімальний розмір тексту — 11px |
| Радіуси | `--radius-sm/md/lg` | 6 / 8 / 12px |
| Відступи | `--space-1…4`, `--tap` | `--tap` = 40px, мінімальна ціль дотику |

Старі імена без визначення (`--border`, `--muted`, `--text-muted`, `--admin-*`) тепер
є аліасами цих токенів.

## Порядок стилів

`src/styles/index.css` підключає файли **в порядку каскаду** — пізніші перевизначають раніші
(це історичні «v0.x/v1.x» шари, розкладені по файлах). Не змінюйте порядок. Стилі,
що належать одному компоненту, лежать поруч із ним (`components/*.css`).

KPI-картки: розмір, відступи й щільність задаються змінними `--kpi-min-h`,
`--kpi-split-min-h`, `--kpi-pad` у `styles/kpi-final.css` (глобальна щільність і
щільність персонального дашборда використовують одне визначення).

## Графіки

Нейтральні кольори ECharts (текст, осі, сітка, підказки) читає `src/lib/chartTheme.ts`
з тих самих токенів. Кольори даних залишаються в `dashboardChartPresentation.ts`.
Якщо токени змінюються під час роботи (перемикач теми), викличте `resetChartTheme()`.

## Доступність

* Єдине кільце фокуса для клавіатури задано в `tokens.css`; не прибирайте `outline`
  у компонентах без заміни.
* `prefers-reduced-motion` вимикає анімації автоматично (додатково до ручного перемикача).
* На пристроях із сенсорним екраном (`pointer: coarse`) основні елементи мають ціль 36–40px
  (`styles/polish.css`).

## Поле періоду

Початок і кінець періоду — по одному полю «дата + час» (`datetime-local`).
Межі доби (00:00 / 23:59) зберігаються як «без часу», тож швидкі періоди та запити
до бекенду не змінюються. Логіка — `src/lib/periodInput.ts` (тест: `tests/period-input.test.mjs`).
